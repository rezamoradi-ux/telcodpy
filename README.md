# TelcodPy - کتابخانه پیشرفته تلگرام 🚀

![TelcodPy](https://img.shields.io/badge/TelcodPy-v1.0.0-blue)
![Python](https://img.shields.io/badge/Python-3.8+-green)
![License](https://img.shields.io/badge/License-MIT-yellow)

کتابخانه قدرتمند و حرفه‌ای برای ساخت ربات‌های تلگرام با قابلیت‌های پیشرفته

## ✨ امکانات

- ✅ پشتیبانی از توکن ربات و اکانت کاربری
- ✅ دکمه‌های شیشه‌ای رنگی با ۱۰ رنگ مختلف
- ✅ پشتیبانی کامل از ایموجی‌های پریمیوم
- ✅ ساخت مینی اپ‌های پیشرفته
- ✅ مدیریت پیام‌ها با دکوراتورهای زیبا
- ✅ بدون نیاز به وب‌هوک
- ✅ کاملاً آسنکرون و سریع
- ✅ بدون باگ و کاملاً تست شده
